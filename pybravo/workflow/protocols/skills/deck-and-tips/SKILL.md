Keep each physical plate and rack as a distinct material. A tip box and the tips loaded in it have independent IDs: select the exact head–tip–box link, not a match by name or capacity. Check the head footprint and plate pitch, then propose only free deck positions that do not conflict with plate moves. A stack needs a verified bottom-to-top order; a buried plate must be destacked before access.

For no cross contamination, keep each tip set dedicated to its source and select compatible fresh tips for the active head; never carry a tip set from one source to another. Reusing a source-dedicated set across two initially empty destination wells needs a compatible method and noncontact contamination assessment; it does not imply a shared aspiration. A rack listed in the catalog is not loaded inventory; record fresh wells only after inspection. For a four-source 384-to-1536 ST10 stamping request, propose four sources stacked in one deck position (source 1 bottom through source 4 top), a work position, a processed-source stack position, one fresh 384-tip set and one distinct ST10 rack per source, four rack positions, and two destination positions. Process the top source first. Propose a one-to-one source/rack/quadrant map (source 1→A1, 2→A2, 3→B1, 4→B2) and use that same quadrant on both destinations. If Labcyte PP/LDV plates are named, select verified matching catalog geometry; never treat a catalog match as physical confirmation. Keep the map, stack order, deck positions, and actual inventory as proposals until the scientist confirms them.
