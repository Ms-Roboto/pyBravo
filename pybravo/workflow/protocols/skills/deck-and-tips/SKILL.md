description: Draft Bravo labware placement and source-isolated tip use from catalog-backed choices.

Keep each physical plate and rack as a distinct material. A tip box and the tips loaded in it have independent IDs: select the exact head–tip–box link, not a match by name or capacity. Check the head footprint and plate pitch, then propose only free deck positions that do not conflict with plate moves. A stack needs a verified bottom-to-top order; a buried plate must be destacked before access.

For no cross contamination, keep each tip set dedicated to its source and select compatible fresh tips for the active head; never carry a tip set from one source to another. Each sample well is its own contamination domain: a tip that aspirates from or mixes in one sample well cannot be reused in a different sample well. Dispensing into a well that already contains sample liquid needs a fresh tip for that sample unless a reviewed method establishes noncontact delivery. Reusing a source-dedicated set across two initially empty destination wells needs a compatible method and noncontact contamination assessment; it does not imply a shared aspiration. A rack listed in the catalog is not loaded inventory; record fresh wells only after inspection.
